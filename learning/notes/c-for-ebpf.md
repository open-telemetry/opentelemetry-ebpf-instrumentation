### 1. 固定宽度整数类型

```c
// eBPF 使用固定宽度类型，不用标准 C 的 int/long
u8   // 无符号 8 位  (0 ~ 255)
u16  // 无符号 16 位 (0 ~ 65535)
u32  // 无符号 32 位
u64  // 无符号 64 位
s32  // 有符号 32 位
s64  // 有符号 64 位

// 为什么？因为 eBPF 需要精确的内存布局来与内核数据结构对齐
```
