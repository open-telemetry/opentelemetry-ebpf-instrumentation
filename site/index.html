OpenTelemetry eBPF Instrumentation telemetry schema

OpenTelemetry eBPF Instrumentation (OBI) publishes the telemetry schema it stamps on its telemetry as schema_url, plus a generated reference of the attributes and metrics it defines.

Telemetry schema

Schema files are served per OBI release version at:

/schemas/obi/<version>

Each file is immutable once published and records the attribute and metric renames between versions, in the OpenTelemetry telemetry schema file format.

Reference
